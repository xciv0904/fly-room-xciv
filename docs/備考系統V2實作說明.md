# 個人化低壓力備考系統 V2

實作日期：2026-11-20。在現有專案內實作與測試，依使用者後續指示推送至原 GitHub Pages 正式網站。

## 從首頁開始

首頁「今天要練什麼？」提供 10／35／60 分鐘入口。時間都是建議配置，不必等待倒數。可以直接口說，也可主動錄音；參考答案預設隱藏。每題可填快速自評，再選擇重答、下一題、下一階段或結束保存。結束時顯示「今天已經完成練習，可以安心休息了。」

| 模式 | 實作流程 |
| --- | --- |
| 10 分鐘 | 一道英文生活／How to／弱點題，回答後比對架構、修正並重答 |
| 35 分鐘 | 弱點複習一題、新題兩題、比對架構、重答；預設英文兩題、中文一題 |
| 60 分鐘 | 弱點一題、英文三題、混合模擬四題、回聽或重答、自評保存 |

首頁可選擇 35／60 分鐘的多語練習方向，包括現有韓文自介。60 分鐘模擬階段也能切換語言；題數或語言不足時以實際題庫為準。可以暫停、跳題、換題、提前結束、直接換模式或選擇今天休息。

原有華航初試、複試專題、真實面試紀錄、完整題庫、三語自介、航點、廣播詞及朗讀中心保留原入口。路由沿用既有 hash router：`#ci/home` 是新版首頁；新子頁為 `#ci/prep/session`、`plan`、`week`、`audit`、`progress`、`history`、`data`，舊路由保持可用。

## 排題與複習

`prep-ui.js` 將既有 `DATA` 與 `CIFinalPrep.registered` 轉成共用資料介面，沒有建立新題庫、產生新擬答或修改原始回答。華航題以 `ci:<原 key>` 識別，其他題以原中英文題面雜湊識別，避免順序調整使歷史紀錄失聯。顯示語言、題型、航空公司、階段、難度和來源；沒有原始難度就顯示「未分級」。只有明確的 `asked`／`peer-asked` 才標為本人實際題／同組考生題，其餘保守標為練習。

`PrepCore.schedule()` 是不需 API 的規則引擎，綜合近期自評較吃力、到期、未練過、本週較少練的類型、指定弱項和模式排序；同分用穩定 ID 決定，結果可重現。35 分鐘的新題階段額外優先未練題；月度自測優先未練或近期未出現的英文題。

一般題七天內降低優先權，弱點和到期複習例外。題庫不足時可安排近期題或減少題數，並顯示原因；同場不重複。換題也排除已換掉的題目，已自評題會留下紀錄。手動「再練一次」隨時可用。

複習規則來自使用者自評：超過十秒開口、內容不完整或頻繁卡住，歸為較吃力，兩天後；五秒內開口、內容完整且自認流暢，十四天後；其他七天後。這是排複習用的自評級距，不是考官或 AI 的客觀評分。畫面顯示每題選題理由和下次日期。

## 紀錄、計時與本機保存

沿用原本 `store`／LocalStorage，新增單一鍵 `fa_prepV2`，結構版本為 1（產品功能名稱為 V2）。包含 settings、plans、sessions、active、audits、monthly。既有儲存鍵、收藏、練習歷史與 IndexedDB 錄音不變。

每場保存開始時間、日期、模式、題目 ID／語言／類型／狀態、實際時間、自評、複習日期和備註。重答前的自評留在 attempts；歷史頁比較同題跨次自評與備註，沒有宣稱自動比較英文能力。原始面試回答與優化參考答案保持分開。

運行中每秒保存檢查點。暫停、切頁、隱藏分頁及離開會停止計時；重新載入後保持暫停，由使用者選擇接續，不會把離線時間加入。跨台北午夜的計時區間分配到各日期；週／月邊界不依裝置時區決定。已保存但未結束的 active 時間和自評也列入累積；模式完成次數只計已結束且選擇完成的場次。提前結束仍保存實際時間。

錄音共用既有 `LabRecorder`，不開啟語音辨識、不上傳、不預設永久保存。可以播放、重錄和下載；拒絕權限仍可手動完成。音訊僅本場暫存，結束本場或重新整理即移除，畫面提示先下載需要的錄音。JSON 不含大型音訊。

## 週計畫、進度與審核

日期一律 Asia/Taipei、星期一開始。每天可設上班／休假／有安排／完全休息，不假定週一至週五上班。參考配置為 35、10、35、10、35、60、休息，共 185 分鐘；60 可取消，每週目標可獨立修改或設 0。沒有補課或跨週債務。

進度 = 當週實際面試分鐘 ÷ 該週自訂目標。70% 起「已達本週目標」、40–69%「有持續累積」、低於 40%「可以依生活狀況調整」；零目標顯示自由練習。計畫時間、暫停時間和審核手動分鐘不加入。

儀表板提供實際分鐘、完成次數、語言／題型分布、自評弱點、複習日期和實際紀錄摘要；不足時顯示「尚無足夠資料」，不推論能力進步。

「生活與學習審核」全部自願填寫：面試、其他教材上的多益分鐘／內容／目標、休息／運動或皮拉提斯／親友相處，以及三個可跳過的反思問題。多益僅存在此手動表單，沒有題庫、練習模式或自動排題，也不影響面試進度。

## 每月追蹤與備份

「我的進步」每月一次抽五題英文。四項 0–5 指標均由自評累積：五秒內開口、結構完整、自然結束、清楚表意；未完成五題只保存練習，不產生完整能力指標。歷史／未來月份需切回本月才能開始。每月顯示實際時間、題次、語言、弱點、練習量差異、自評長條與表格。自評和系統直接記錄的時間／題次分開；沒有前月資料不產生虛假趨勢。

「資料與設定」可匯出／匯入備考 JSON，也已加入原「成果與備份」的全站備份。先完整驗證版本、日期、選項、有限數值、唯一題目、時間總和、複習間隔、月度五題與對應紀錄，再寫入；無效檔案不覆蓋資料。不支援的未來版本會拒絕，避免猜測升級。損壞的本機原始 JSON 保留並提供原檔匯出，不默默重設。

資料不會自動跨裝置同步。備考匯入不改寫題庫、收藏或錄音；靜態快取更新為 v30，不會清除 LocalStorage／IndexedDB。

## 測試結果

- `npm run build:vocabulary`：通過，1,185 篇既有來源文章保持。
- `npm test`：111 項通過，其中新增核心 24 項、頁面 9 項。
- `npm run test:prep`：完整新版瀏覽器驗收通過，零頁面執行錯誤；八種畫面在 390／768／1280 寬度驗證，共 24 張截圖。
- `npm run test:final`：通過；192 個複試單元、精選 50 題、三筆真實紀錄、原文保留、收藏／備份及中英文錄音。
- `npm run test:browser`：通過；既有朗讀、錄音、逐字稿、IndexedDB、備份及響應式流程。
- `npm run test:center`：通過；四航空公司、航點、原文正式題庫、計時、錄音及中斷恢復。
- `npm run test:curriculum`：通過；課程、六主題、64 篇真實來源、錄音比較與保存。

新版瀏覽器驗收包括首次空資料、三模式全部階段、思考略過、暫停排除時間、跳題／換題／重答、模式切換與提前結束、重新整理、班表／休息／新週、目標比例、多益分鐘隔離、五題月測、合法與非法 JSON、全站先驗證再匯入、假裝置錄音、拒絕權限後手動完成，以及原功能入口。

核心另測題庫不足、台北週／月界線、2／7／14 天、零目標、active 進度不重算、非法索引／真假值。未發現 80 分鐘模式。

限制：自評不能取代客觀英文能力評分。錄音與手機版驗收使用 Chromium 假麥克風及尺寸模擬，沒有實體 iPhone／Safari 驗證。改寫題面可能視為新題，原 ID 歷史仍保留；移除題目的紀錄保留 ID，不會刪除。沒有後端或自動跨裝置同步。
