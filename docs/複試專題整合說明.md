# 華航複試專題整合

本文件說明複試專題的網站整合與驗證方式。雙語內容整理日期為 2026-11-08。

## 內容與入口

- 「華航首頁 → 複試準備 → 複試專題・39 題雙語擬答」為主要入口；面試回顧與模擬面試也能進入。
- 39 題包含 4 題本人記錄已問過的題目、6 個新聞主題與 7 個延伸追問、2 題年度／初試延伸議題、18 題履歷服務題，以及英文核心另外需要的 2 題。
- 上一份清單的六組英文問法連結既有答案，其中「Why China Airlines, and why now?」對應兩題，不重複製作另一份答案。
- 每題有中英文題目與擬答、回答提醒、資料來源；新聞另附發布日期、事件／措施日期與查核日期。只有四題使用「回顧已問過」標籤，推估題不標成考古題。
- 需要本人確認的準備、證照及近況另行標示。加拿大租車與哥倫比亞線上報到故事分開；碰觸事件屬假設，不能說成真實經歷。

## 可用流程

1. 選「先練重點」、回顧、新聞、年度、履歷、英文核心或弱點；也可搜尋題目與答案。
2. 展開題目，先自行回答，再按「查看中英文擬答」；可切換中文、English 或中英對照並聽示範。
3. 主題與追問互相連結；點擊會帶到指定題，清除妨礙該題顯示的篩選條件。
4. 中文／英文錄音直接帶指定題目進入原有模擬介面。錄音後可回聽、下載音檔、修正逐字稿、對照擬答與存入紀錄；可回到原題。
5. 收藏沿用原有弱點與間隔複習機制。搜尋、分類、語言及最後展開題目保存在本機，題目網址支援重新整理與返回。
6. 可下載全 39 題 Markdown；網站內容與下載檔由同一份資料產生。

## 資料與紀錄

- `ci-final-data.js` 是雙語內容與來源的單一資料來源，亦可由 Node 匯入並呼叫 `markdown()` 產出學習檔。
- `hydrateQuestionBank()` 先照原本順序配置題庫編號，再呼叫 `CIFinalPrep.attach()`。11 題沿用既有編號，僅更新華航專屬擬答；其他航空公司原始擬答保留。
- 28 題新增內容使用保留區間的固定負數編號，不改動既有收藏、練習次數與舊模擬紀錄。
- `ci-final-study.js` 負責專題介面；`ci-mode.js` 與既有路由處理 `#ci/final-topics` 及 `#ci/final-topics/<key>`。
- 模擬紀錄新增可選的 `questionKey`，讓不同問法能對回同一題；舊紀錄仍可讀取。備份加入專題偏好，並保留題目 key。
- 指定華航時，擬答比對使用華航版本，避免顯示的答案與分析參考不同。
- 面試回顧的原始作答保持原樣；四題目前優化版本改讀最新雙語資料，另修正過時的「第一次應徵」說法。
- 英文擬答依既有詞彙建置流程歸入面試段落，不得加入華航正式原文朗讀池；原文朗讀池的來源限制維持不變。

## 驗證

- `npm test`：全站既有測試及新增的雙語清單完整性、編號保留、其他航空版本保留、重複載入與下載檔一致性。
- `npm run test:final`：複試入口、分類搜尋、七題英文核心／六組問法、雙語顯示、來源與追問、弱點及重新整理、中文英文錄音、音檔及學習檔下載、紀錄與備份，以及 390／768／1280 寬度。
- 瀏覽器錄音檢查使用模擬麥克風，不能據此宣稱已在實體 iPhone／Safari 驗證。
- 新增靜態資源與 service worker 同步使用 v21。上線前仍需另行檢查正式部署、正式資源與實際裝置行為。
