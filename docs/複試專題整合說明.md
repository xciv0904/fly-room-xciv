## 練習與下載

1. 「華航首頁 → 複試準備 → 複試精選」進入 50 題。另可直接進入誠實溝通、社群形象與航空業時事。
2. 用「主題分類」查看六類；「題型與來源」則保留回顧、時事、假設情境、英文核心與弱點等條件，兩者可交叉篩選。
3. 「練習範圍」可切到完整 77 題。直接連結或追問若指向延伸題，會切到可顯示該題的範圍，不刪除或改寫舊紀錄。
4. 每題先回答，再看中英文擬答與提醒，可聽示範、收藏、指定題目錄音、回聽、下載音檔、比對擬答及儲存。
5. 下載依練習範圍產出完整的 50 題或 77 題文件，不因暫時搜尋或分類而只匯出一部分。網站與下載檔使用相同資料及六大分類。
6. 精選文件為 `華航複試精選50題-2026-11-10.md`；完整文件為 `華航複試雙語擬答-2026-11-10.md`。

## 資料與相容性

- `ci-final-data.js` 的 `topics` 明列精選順序與分類；`essentialItems` 必須恰為 50 題，每個完整題庫項目都須被分類一次。未選入不代表內容無效。
- `CIFinalPrep.attach()` 仍在既有題庫編號配置後執行。原始題庫與其他航空公司擬答保留；華航版本與既有自我介紹別名維持同步。
- 新題只接在原有 63 題之後，使用固定負數編號。`essentialRank` 是畫面排序，不取代保存紀錄用的 `id` 或 `key`。
- 路由仍使用 `#ci/final-topics` 與 `#ci/final-topics/<key>`。新版偏好保留範圍、分類、來源、搜尋、語言及展開題目；收藏與 IndexedDB 錄音沿用原機制。
- `markdown()` 預設匯出精選 50 題；`markdown({scope:'all'})` 匯出完整題庫。舊題查核日不因重新選題改成新日期。
- 詞彙建置仍將擬答歸入面試段落，不能進入華航正式原文朗讀池；原 64 篇來源與歷史詞彙 ID 必須保留。
- 變更的執行腳本與 service worker 快取同步升為 v24。

## 驗證方式

- `npm test`：清單完整性、50 題及分類唯一性、既有題號與其他航空版本、下載檔一致性及全站既有測試。
- `npm run test:final`：精選入口、六分類、完整題庫、深連結、雙語、追問、收藏與重新整理、中文英文錄音、下載、備份及 390／768／1280 寬度。
- 瀏覽器錄音使用模擬麥克風；不能據此宣稱實體 iPhone／Safari 已驗證。正式發布仍需等待最終 Pages 工作並核對正式資源及操作。
