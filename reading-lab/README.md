# English Reading Lab

Fly Room 的獨立前端功能。入口是首頁「英文朗讀實驗室」或「更多」，網址路徑為 `#readingLab`。既有 `ci/broadcast`、雜誌、題庫、設定、錄音資料庫及 localStorage 鍵均維持原樣。

## 架構

| 檔案 | 職責 |
| --- | --- |
| `data.js` | 保留舊版模擬資料與原有單字、字尾、地名識別碼；舊模擬版本不進入正式抽題 |
| `source-articles.js`、`curriculum.js`、`curriculum-ui.js` | 官方延伸來源與 PDF metadata、六主題涵蓋、文字負擔、可解釋抽題及複驗介面 |
| `ci-destinations.js` | 整合使用者七張截圖的 80 個地名、代碼、近似拼讀及易錯提示；與既有資料合併後共 95 項，保留既有 ID 與收藏／自測紀錄 |
| `core.js` | 逐詞編輯距離、差異分類、人工確認資料、日期／連續天數／七日統計、備份驗證與合併 |
| `db.js` | 獨立 IndexedDB：`fly-room-reading-lab`，stores：`meta`、`sessions`、`audio` |
| `media.js` | MediaRecorder、選擇性 Web Speech 辨識、停止與釋放麥克風、Blob 播放 |
| `app.js` | 六個功能分頁、準備與朗讀流程、草稿恢復、個人弱點、自測、每日清單、備份與刪除 |
| `lab.css` | 沿用原站配色／卡片，補充手機、平板、電腦排版 |

新增測試依賴只用於開發；網站不需要 npm、打包、伺服器或 API 金鑰。

## 操作與資料

1. 正式模擬使用華航完整原稿，可按材料分類、主題與篇幅標籤篩選，指定文章或依缺口安排原稿。
2. 選立即朗讀／15 秒／30 秒。開始準備時出現原稿；倒數歸零後，由使用者按「開始錄音」或「開始計時（不錄音）」。這保留瀏覽器要求的使用者操作與明確麥克風授權。
3. 錄音直到使用者按停止；停頓、辨識服務中止不會結束錄音。也可匯入不超過 50 MB 的錄音，自行輸入秒數。
4. 貼上辨識結果或自行聽寫，進行文字比對。所有建議預設未確認，回聽後可勾選、分類、加註說明，或修正逐字稿重新比對。重音／流暢度／語調只能人工加入。
5. 儲存時保留原稿快照、逐字稿、實際秒數、難度、筆記及人工確認問題。錄音 Blob 放在 IndexedDB，不放進 localStorage。停止後的音檔及文字草稿可於重新整理後恢復；**錄音進行中不可期待瀏覽器在關閉或重新整理時保留尚未完成的音檔**。
6. 字庫先試讀或錄音，再揭曉 IPA／重音提示及中文，自評後進入複習清單。起始的 24 個辨識落差全部標為待確認，不算已確定發音錯誤。
7. 每日四項以實際一輪訓練完成即可，不要求大量刷題；分鐘數為時間分配建議，不是強制刷題門檻。以裝置當地日期計算連續完成天數。
8. 備份預設包含完成的紀錄、單字自評、地名自測／收藏、每日完成狀態，可選擇額外包含正式朗讀錄音。單字猜讀音檔及尚未儲存草稿不在匯出範圍。含錄音備份限 60 MB 原始音檔，匯入檔案限 100 MB。重複紀錄 ID 略過，新的紀錄合併，不取代目前草稿。備份驗證成功後以單一 IndexedDB transaction 匯入。
9. 可只刪一筆音檔、刪整筆紀錄、或刪實驗室所有資料；原站資料不受影響。刪除不可還原，應先備份。瀏覽器清除網站資料、私密模式或儲存空間不足仍可能造成資料無法保存。

## 材料與讀音來源

- 正式題庫為 64 篇華航原稿；五篇官方延伸閱讀任務另列於學習模式。舊版 288 個原創模擬版本只保留歷史相容性，**不是 288 篇獨立官方新聞，也不參與正式抽題**。篇幅標籤與文字負擔線索均非官方考試難度。
- 每篇提供來源、發布期別或已知日期與出處範圍；未知日期保持待確認。原文練習材料與考生回報不會被標成已確認官方考題。
- 華航代表航點採[官方全球航點圖](https://www.china-airlines.com/at/en/Images/全球航點_260131_tcm283-57777.pdf)的東京、西雅圖；西雅圖另可核對[官方航線說明](https://www.china-airlines.com/en-us/noa_20240308_seatpe)。長榮代表航點巴黎、維也納核對[官方業務／航網資料](https://www.evaair.com/en-global/about-eva-air/about-us/market-and-sales-overview/main-business-and-services/)。查核日期為 2026-10-15，並非完整航網、不保證未來班表。
- 使用者後續提供的七張截圖另整合 80 項：日本 19、韓國 5、東南亞 16、港澳／中國大陸與其他亞洲 17、歐洲 11、北美洲 7、大洋洲 5。東京、西雅圖、維也納、巴黎與原資料合併，不重建既有 ID。名稱、代碼、拼讀來自使用者提供的表格；營運方式另連結[華航官方時刻表](https://booking.china-airlines.com/Flightschedule/)與[全球航點](https://www.china-airlines.com/tw/en/itinerary-booking/flight-information/global-destinations)。這不是 80 個現行華航自營直飛航點的宣稱；日本清單保留集團／季節／歷史地名註記，巴黎等歐洲延伸城市與基督城明確標為延伸參考。可按地區、中文、英文、機場代碼篩選，亦可由速查表切換到自測卡、收藏或隨機自測。
- 單字 IPA／重音為人工整理的常見讀法，提供 Cambridge 詞典核對入口；例如 [fuselage](https://dictionary.cambridge.org/us/pronunciation/english/fuselage)、[commemorative](https://dictionary.cambridge.org/pronunciation/english/commemorative)。`exquisite` 有不同重音讀法，不能把其中一個當成唯一正解。
- 二延平與 Karlovy Vary 未假造標準英語 IPA，以清楚標示的近似讀音提示及地名來源提供練習。地名分別顯示英文提示與必要的當地語言差異。Collins 搜尋入口供使用者核對，不宣稱每個複合名稱都有獨立詞條。
- 全部站內示範按鈕使用裝置 TTS，**不是官方標準音檔**。裝置聲音、支援的語音與地方名讀法可能不同；無 TTS 時提供參考連結。

## 隱私與第四期界線

一般錄音、音檔匯入、播放、貼稿及文字比對都在本機進行。本實驗室沒有 `fetch` 上傳音檔、外部分析 SDK 或公開前端 API 金鑰。

瀏覽器語音辨識依使用者開關選擇；正式模擬預設開啟，可關閉。啟用時瀏覽器可能使用自己的雲端語音服務，介面已告知。辨識支援程度、準確度與是否連網由瀏覽器決定，錯誤時保留錄音與人工貼稿流程。

文字相似度只計算文字差異，不能用來判定音素、聲音溫暖度、流暢度、語調、真實發音品質或面試分數。第四期音素級服務未接入：需要另行選定可靠服務及安全的後端金鑰管理，取得上傳音訊的明確同意後才能加入。

## 驗證與部署

```sh
npm ci
npx playwright install chromium
npm test
npm run test:browser
```

`npm test` 包含原文與字詞擷取覆蓋回歸，以及題庫矩陣、差異類型、每日資料、備份、真實 IndexedDB API（測試替身）、錄音生命週期等測試。瀏覽器測試使用 Playwright 虛擬麥克風，不接觸私人錄音；涵蓋開始／停止／本機播放、倒數、手機／平板／電腦、貼稿、人工確認、備份含音檔往返、逐項每日完成及原站回歸。權限拒絕和不支援錄音時的流程亦有測試。實體 iPhone／iPad Safari、Android Chrome 及真人麥克風仍建議在合併前由使用者做一次試錄。

以 `codex/english-reading-lab` 提供 Pull Request。審閱後合併至 `main`，既有 GitHub Pages 流程即可部署，無建置步驟；正式入口將是 `https://xciv0904.github.io/fly-room-xciv/#readingLab`。分支未合併前，正式站不會出現新功能。Service Worker 快取名稱及受影響資產版本已更新為 v20。

## 主題與複驗流程（v20）

- 六個主題涵蓋航空服務、餐飲設備、永續環境、企業科技、文化人物與生活旅遊。指定文章與正式抽題皆可按主題篩選；同一原文的重錄不增加涵蓋篇數。
- 正式模擬沿用 64 篇完整華航原稿。另有五篇官方來源閱讀任務補足降噪耳機、米香、SAF、齊柏林與台積電 ESG；站內只放短節錄，全文由來源網站提供，不將短摘錄充作完整模擬題。
- 58 篇原稿補上對應期別的原始 Dynasty PDF。網址核對與逐句內容核對分開標示；既有原稿、文章 ID 和歷史錄音維持原狀。
- `curriculum.js` 提供可重現的主題涵蓋與原稿建議，先選未練原文，再參考主題缺口及人工確認的問題。句長、專名、數字、縮寫與字典詞頻是各自可檢查的線索，不是面試分數。
- 每輪可選最多三個已確認問題，練原句並建立新一筆重錄。兩次錄音分開保存、播放及下載；新的實際練習加上明確自評，才會改變問題的複驗狀態。局部試錄供當輪回聽與下載，不列為完整朗讀紀錄。
- 同題自評改善後保留換文待複驗，隔日顯示提醒；換文必須是另一段包含完整目標片段的原文。沒有可用文章時維持待複驗。後續再出現問題會重新開啟，並保留既有證據。
- 重新比對逐字稿會保留已確認問題的 ID、筆記與歷史標記。備份／還原保留重錄關聯、人工結果、延伸閱讀時間與原有資料；不自動把辨識差異視為發音錯誤。

驗證：`npm test`、`npm run test:browser`、`npm run test:center`、`npm run test:curriculum`。瀏覽器錄音測試使用 Chromium 模擬裝置，不代表實體 iPhone／Safari 驗證。
