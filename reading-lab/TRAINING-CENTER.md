# 英文朗讀訓練中心

## 架構盤點與保留範圍

原站是 classic JavaScript＋HTML/CSS 靜態網站，沒有伺服器框架或付費 API。初試、複試、完整題庫、華航首頁、原站 localStorage 設定全部保留。沿用 Reading Lab 路由 `#readingLab`、既有詞庫產物、IndexedDB `fly-room-reading-lab` 的 meta/sessions/audio 三個 store，沒有新建另一套網站或清除資料庫。

詞庫 PR #2 與朗讀中心 PR #3 已合併並部署至 main。本輪在 `codex/recording-reliability` 修正自動紀錄與錄音中斷保護。

## 華航原稿限定與手機完成流程（2026-10-16）

- 正式模擬改用既有文章索引的 64 篇華航材料：39 篇雜誌、20 篇新聞稿、5 篇廣播詞；每篇全文不同。`learning.examPool` 統一提供指定選篇、隨機、學習轉考場與重練，不再讀取舊自製題庫。
- 移除 288 自製模擬版本與湊篇幅篩選；預設全部難度，可依材料類型及篇幅粗分難度。隨機優先未練習原稿，仍有其他文章時避免連續抽到當前文章。歡迎廣播保持原稿完整。
- 正式考場公司固定華航。舊公司的設定在開啟時轉為華航；自製或非華航草稿若有實際練習，先保存為歷史再退出考場。歷史可回聽下載，但不提供重練封存的自製稿；不清除歷史與錄音。無法載入文章索引時不執行封存遷移，避免離線時誤清資料。
- 手機錄音期間「儲存／比對」不再灰化，而改為「停止並儲存／停止並比對」。沒有辨識文字仍保存音檔並引導貼稿。停止時至多等 1.2 秒收取辨識服務最後結果，不再立即丟棄最後一句。
- 草稿與歷史的音訊播放器均提供直接 Blob 下載連結。iPhone 若將音檔開啟而非下載，介面提示透過分享選單儲存到「檔案」。沒有上傳錄音。
- 單元及瀏覽器回歸涵蓋來源全文相等、華航與類型限制、舊模擬草稿含錄音的封存遷移、錄音中儲存／比對、手機寬度下載檔案大小與原 Blob 一致。測試為 Chromium 模擬裝置，不聲稱已在實體 iPhone/Safari 驗證。

## 錄音與文章學習修正（2026-10-16）

- 正式模擬開始即建立獨立歷史紀錄；每次音訊檢查點以單一 IndexedDB transaction 同存原稿、時間、逐字稿、草稿與歷史音檔。停止後自動保存，不要求逐字稿，也不要求按儲存。新一輪使用新 ID，不覆蓋上一輪。
- 逐字稿預設啟用，使用者可關閉並保存選擇。介面明示瀏覽器辨識可能傳送音訊至辨識服務；關閉仍可錄音與自動留存。
- MediaRecorder 意外停止或音軌中斷會收尾、保存並提示，不再讓畫面誤以為仍錄音。辨識結束只重啟辨識，不停止錄音。設定的朗讀時限仍有效，可選不限時。
- 開始錄音重繪後保持可見原稿的位置；若原稿已不在畫面，就顯示原稿開頭。
- 文章學習只包含雜誌、新聞稿、廣播詞。舊有其他類別篩選自動忽略，不刪原始材料、詞庫或既有歷史。
- 測試涵蓋 16 秒連續 MediaRecorder 錄音與音檔解碼、辨識結束後持續錄音、無逐字稿的歷史保存、意外中斷保存及手機捲動。測試使用 Chromium 模擬裝置，不保證所有 iPhone/Safari 系統中斷行為，也無法還原從未成功寫入的舊錄音。

## 能測量什麼，不能判定什麼

### 聲線、分句與詞典原音（2026-10-16 更新）

`speech.js` 統一處理學習、單字與地名的合成播放：只列裝置英文聲線，支援 en-US／en-GB 與聲線試聽，保留使用者設定；voiceschanged 延遲載入時更新選單。預設自然速度 1 倍（已儲存的舊速度不強制覆寫），音高固定正常值，由引擎處理自然語調，不逐詞任意調音高。

先分完整英文句子；常見稱謂如 Mr./Dr. 不獨立斷句。太長的句子才在標點或必要的詞邊界分段。每段等 onend 再插入 0.18／0.42／0.9 秒留白，可只聽一句、顯示目前句子、停止後取消排隊，切換頁面／文章／聲線也會停止。不提供「等同真人」或「劍橋聲線」保證。口音未安裝時明示實際 fallback，6 秒未收到啟動事件會停止並提示替代操作；這不能偵測系統音量是否為零。

單字另有 [劍橋 UK／US 真人發音入口](https://dictionary.cambridge.org/pronunciation/)，另開該詞頁後按 UK／US 喇叭。依 [Cambridge 資料授權說明](https://dictionary.cambridge.org/license.html)，本版不爬取、轉存、代理或嵌入其音檔；沒有放 API key。既有 IPA 仍是原本鎖定版美式資料，不標為劍橋資料，也不因選英式聲線就冒稱 IPA 已轉英式。專名／屈折字若詞典沒收錄，需另查可靠來源。

語音佇列／口音／取消回呼／停頓測試使用測試引擎，證明程式行為，不證明真人聽感。最終自然度仍需本人用實際裝置聲線試聽；App 內嵌瀏覽器若不支援，可用 Safari／Chrome 開啟同一預覽網址。

聲線篩選修正：每種口音只保留一男一女，優先選可辨識的一般高品質聲線。Web Speech 不提供標準性別欄位，因此只收錄已明確識別的具名聲線；未知名稱不猜性別，也不補進名額。排除 Mac 的唱歌／音效／耳語／機器人，以及舊式角色聲線（含 Bad News、Bells、Boing、Whisper、Zarvox、Fred、Eddy 等）。不再提供展開其他聲線的選項；篩選不等於已完成真人音質評測。

自選只在同口音的男女兩個候選內運作；缺少任一聲線就明示，不退回另一口音或系統猜測，也不以調整音高冒充男／女聲。原有自選設定仍保存；不再使用舊版展開或隱藏選項控制播放。未修改 macOS 設定、未下載任何聲線或付費服務。

- Tone of Voice、Fluency、Eye Contact 等六項預設全部「待人工確認」。自評「穩定／需要重練」由本人選擇，不從文字差異或波形推導。
- Volume 顯示 RMS／峰值 dBFS 與接近滿刻度樣本比例，是數位相對值，不是現場分貝，也不宣稱音量合宜。
- Pausing 使用 20ms 視窗、-40dBFS 門檻、至少 0.6 秒安靜區間。若有多聲道，採整段 RMS 較大的聲道。背景噪音、麥克風增益、降噪可能影響結果；沒有斷定換氣錯誤或不流暢。
- WPM 來自本人填寫的已讀字數／時間，或逐字稿字數／時間，明示來源；不是自動辨識出的實際語速。完成度只採本人填的原稿已讀字數，未填就待確認。
- Accuracy 沿用原稿／逐字稿比對；辨識落差只供回聽，不自動確認為發音錯誤。
- 影片只在本頁暫時播放，不儲存影片本體、不上傳；眼神／表情／站姿清單只表示已檢視，不表示合格。
- 意群斜線只依標點與連接詞粗切；粗體是值得預習的詞，不是唯一句意重音。音節與重音沿用已有字典證據；缺少資料就待確認，合成音尤其可能誤讀外語地名。

本機波形分析限制：20 MB、10 分鐘以內；解碼失敗時保留原錄音回聽與人工自評，不阻止儲存。Safari／iPhone 是否支援匯入格式，需實機測試。

## 錄音與資料保護

MediaRecorder 每秒有可用片段時嘗試將目前累積音訊及草稿寫入 IndexedDB，切到背景時再請求片段；重開頁面還原最近成功的檢查點並提示確認尾端。beforeunload 會在練習中要求離開確認，但 iOS 強制關閉或系統暫停不保證觸發事件，最後片段仍可能遺失。請保持螢幕開啟、完成後按停止；這不是零遺失保證。

核心功能不啟用語音辨識服務。使用者可自行勾選瀏覽器辨識，但會先看到可能送交瀏覽器服務的提示。音訊分析在本機，沒有上傳 endpoint。可刪除單筆錄音、整筆紀錄或朗讀實驗室全部資料，並保留原站資料；新版欄位支援既有備份匯出／匯入。

## 本機預覽與驗收

```sh
npm ci
npm run build:vocabulary -- --refresh-lexicon
npm test
npm run test:browser
npm run test:center
python3 -m http.server 4173 --bind 127.0.0.1
```

開啟 `http://127.0.0.1:4173/#readingLab`，使用原有通關密碼登入。本機 origin 與正式站不同，資料庫亦隔離，**預覽不會自動帶入正式站的個人紀錄**；若要測匯入，請先在正式站備份，並只在預覽匯入副本。

- `npm test`：原有測試加上複習日期、波形／人工評估界線、備份與地名來源測試。
- `test:browser`：原本考場、倒數、錄音、比對、每日任務、備份、地名、手機／桌機回歸。
- `test:center`：四家航空學習、字典與提示切換、原站文章模擬、時限自動停止、本機合成 WAV 解碼、手動眼神狀態、間隔複習、強制重整後音訊檢查點恢復、390/768/1280px、模擬裝置錄音。

瀏覽器測試使用 Chromium 與模擬麥克風，不冒稱實體 iPhone／Safari 或真實麥克風均已通過。所有測試攔阻外站請求。正式部署前仍請本人在 iPhone 試一次錄音／停止／播放、切背景／重開及刪除，再確認 UI。
